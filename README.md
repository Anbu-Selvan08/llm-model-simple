# LLM AI Chat Bot App Starter Setup

This template provides a minimal setup to get React 19 working in Vite with HMR and some ESLint rules.
This is just a Small Version of LLM which is very Simple and Free to Use model.

Which contains :
  1,500 Request per Day (RPD)
  15 Request per Minute (RPM)
  1 Million Token per Minute (TPM)

It is Starter of A LLM and Need to update it for yourself , It is just a Blueprint for the LLM.
